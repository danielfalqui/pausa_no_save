# Pausa no Save

Blog pessoal de reviews de jogos, com destaque para RPGs, jogos de captura de criaturas e clássicos.

## Páginas
- `index.html`: apresentação pessoal e destaque para as reviews mais recentes.
- `reviews.html`: review de Cassette Beasts.
- `yakuza.html`: review de Yakuza: Like a Dragon.
- `world-of-final-fantasy.html`: review de World of Final Fantasy.
- `rpgs.html` e `classicos.html`: páginas para reviews futuras.
- `contato.html`: apresentação da equipe e formulário de contato.

## Antes de publicar
1. Em `script.js`, troque `CONTATO_DA_EQUIPE@exemplo.com` pelo endereço que receberá mensagens. O formulário abre o aplicativo de e-mail do visitante.
2. As imagens de Pikachu/Pichu e Cloud vêm de fontes externas. A imagem do sprite Cloud tem uma alternativa de pixel art caso o primeiro endereço não carregue; os créditos e links ficam no site. As imagens externas exigem internet.

## GitHub Pages
Envie todos os arquivos e a pasta `assets` para a raiz do repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, escolha sua branch principal e a pasta `/(root)`.
